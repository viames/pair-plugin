Privacy

Pair for Codex is a collection of skills and reference documents maintained by Viames Marino. The plugin has no independent server, telemetry, account system or credential store. It does not require an API key.

Your host and workspace

The host agent may read project files, send context to its model provider and run tools while following the skills. Those operations use the host's permissions and policies. Installing these instructions does not create a separate sandbox or prevent data from leaving the host.

Review the privacy settings and policies of the Codex/model service you use. Keep secrets and private application data out of public issue reports.

This website and downloads

This static site does not add analytics, cookies, forms, external fonts or tracking scripts. GitHub hosts the site, repository and release downloads and processes requests under its own privacy statement.

Questions

Use GitHub Issues for non-sensitive questions or reproducible bugs. Issues and their attachments are public.
