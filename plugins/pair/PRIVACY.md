# Privacy

Pair is maintained by Viames Marino and distributed under the MIT license.

This package contains skill instructions, supporting references and visual assets. It runs no server or background process and has no telemetry, account system, credential store or independent network transport.

When a skill is used, the host agent may read project files, inspect configuration, run commands or contact services needed for the user's task. The host controls tool access, permissions, logging and model communication. Code, tool results and other content in a chat may be processed by the host's model provider under that host's policies. The plugin's instructions do not create a separate sandbox or change those policies.

The package itself requires no API key. Applications being developed may have their own credentials and privacy obligations. Do not include secrets or private application data in public issues, screenshots or test fixtures.

GitHub hosts the source, release downloads and project website. GitHub processes requests under its own policies. The project website includes no analytics scripts, forms or third-party fonts. GitHub issue reports are public unless a separate private reporting channel is agreed.

Public privacy page: https://viames.github.io/pair-plugin/privacy.html
